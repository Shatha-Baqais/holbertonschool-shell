# Shell, init files, variables and expansions

## Description
This project covers shell initialization files, variables, expansions, arithmetic and aliases.

## Files
| File | Description |
|---|---|
| `0-alias` | Creates an alias named `ls` with the value `rm -f *` |
| `1-hello_you` | Prints hello followed by the current Linux user |
| `2-path` | Adds /action as the last directory in PATH |
| `3-paths` | Counts the number of directories in PATH |
